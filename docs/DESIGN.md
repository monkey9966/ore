# 技术方案: 基于 ToF 相机的传送带矿石粒径测量

## 1. 需求与目标

- 用 ToF 相机(Vzense **DS63**)俯拍传送带上的矿石堆(存在堆叠);
- **只测量轮廓完整可见的矿石**: 被压在下面、被部分遮挡的矿石自动剔除, 宁可少测、不能测错;
- 输出每颗矿石的**最大边长**(最大 Feret 直径)与**粒径分布**;
- 粒级: 100–200 / 200–300 / 300–400 / 400–500 / ≥500 mm, **100 mm 以下不统计**;
- 支持办公室静止场景验证(无皮带、无编码器)。

## 2. 硬件与安装(DS63)

| 项目 | 参数/决策 |
|---|---|
| 传感器 | CW-iToF, 深度 640×480@30fps, FOV H67°×V50°, 量程 0.15–5 m, 精度 <1% |
| 安装 | 正俯视, 宽视场方向横跨皮带; 1.2 m 高度处视场约 1.58×1.12 m, 分辨率约 2.5 mm/px |
| 分辨率余量 | 100 mm 矿石约 40 px, 500 mm 约 200 px, 充足 |
| 触发(产线) | 皮带编码器分频接 Ext_trigger 硬触发, 定距拍摄; 触发间隔下限 34 ms(约 29 fps 上限) |
| 触发(办公室) | 连续流/软触发, 静止场景 |
| 曝光 | 手动固定曝光; 30fps 档最大 450 µs, 皮带 2 m/s 时运动模糊 <1 px |
| 环境 | 940 nm 抗日光较好; 环境照度须 <10 万 lux, 建议遮光罩+防尘 |

### SDK 滤波器配置(ScepterSDK)

| 滤波器 | 配置 | 原因 |
|---|---|---|
| Confidence Filter | **开** | 剔除黑/湿矿石低信号点, 是算法"无效区"的来源 |
| Flying Pixel Filter | **开** | 消除轮廓边缘飞点 |
| Spatial Filter | 开(弱) | 压平面噪声 |
| Time Filter | **关** | 皮带在动, 时间滤波会拖影 |
| FillHole | **关** | 算法需区分"真实表面"与"编造插值", 完整性判定依赖真实无效区 |

## 3. 算法流水线

数据接口: 算法唯一输入是标准化 `HeightFrame`(正射高度图, mm 单位, 含有效掩膜),
与相机解耦; 合成数据与真机数据走同一条流水线。

```
深度图(透视) ──> [真机路径] 点云 -> RANSAC基准面 -> 正射投影(z-buffer) ──┐
                                                                     v
合成生成器 ──────────────────────────────────────────────> HeightFrame(3mm/px)
                                                                     |
   Stage A  预处理: 小洞最近邻填补(大洞保留无效) + 局部基准面(分块中值下采样
             + 灰度开运算 r=300mm) -> 凸起图 prominence = H - base
                                                                     |
   Stage B  分割: 前景(prominence>40mm) -> 中值滤波去飞点尖刺 -> 高斯平滑(9mm)
             -> 细种子 h-maxima(8mm) -> 分水岭(过分割) -> 鞍点层次合并(18mm)
             -> 小区域(<80mm)标记为碎料(保留标签供邻接判断)
                                                                     |
   Stage C  边界分类: 沿轮廓逐点, 比较 h_in(掩膜内中值) 与 h_out(guard带外中值)
             规则1 跌落:   h_in - h_out > 15mm            -> FREE(自由边界)
             规则2 并排:   自身轮廓与外侧都低于腰线(base+0.55*相对高度) -> FREE
             外侧无效数据                                  -> INVALID
             其余(被更高邻居压住)                           -> OCCLUDED
             * 分水岭脊线归属自动解算: 高的一方FREE, 低的一方OCCLUDED
                                                                     |
   Stage D  完整性判定(全过才接受):
             1 FREE占比>=85%          -> 拦被压/遮挡
             2 INVALID占比<=5%        -> 拦轮廓贴深度空洞
             3 不触碰ROI边缘(15px)    -> 拦出画
             4 掩膜内有效像素>=90%    -> 拦大面积无回波
             5 solidity>=0.85         -> 拦轮廓缺损
             5b 椭圆拟合IoU>=0.90     -> 拦"葫芦形"欠分割双胞胎
             5c Feret<=1.08*椭圆长轴  -> 拦附着邻块导致的尺寸虚大(交叉校验)
             5d 表面无双峰(谷深>=10mm且第二峰达矿石尺寸即拒)
                                      -> 拦外形光滑的欠分割合并体(MULTI_PEAK)
             6 最高点在掩膜内部       -> 拦"大矿石露出的一角"
             7 粒径>=90mm             -> 拦碎料
             每颗输出拒绝原因码, 供现场调参
                                                                     |
   Stage E  测量: 最大Feret直径(最大边长) / 最小外接矩形长宽 / 等效圆直径
             / 厚度(凸起99分位) / 体积(凸起积分)
             分箱依据默认用次轴(min_rect_w, 与筛分孔径可对标), 可配置
             厚度交叉校验: 厚度>1.10*次轴 即拒(TOO_THICK, 平躺单块矿石
             厚度不会超过次轴, 过厚说明是上下两块矿石叠合的合并体)
                                                                     |
   Stage F  跨帧去重(产线, tracking.py): 编码器已知帧间位移 -> 质心平移预测
             -> 贪心最近邻匹配(门限~60mm) -> 同一矿石多帧测量取中值
             -> 质心移出视场或连续2帧未匹配时结算一次
                                                                     |
   Stage G  统计: 分箱计数/按体积加权占比/D50/滑动窗口; 附可测率等健康指标
```

### 完整性判定的物理依据

俯视高度图中, **只有位于堆顶层、整圈轮廓边缘都"向下跌落"的矿石才是完整可见的**。
被压在下面的矿石, 其可见边界上必然有一段与更高的矿石相接(OCCLUDED 边界),
从缝隙露头的矿石大部分边界都是 OCCLUDED, 自动被拒。
并排接触(两颗矿石裙边相碰)不算遮挡——双方接触处都在各自腰线以下, 规则 2 放行。

### 关键参数(PipelineConfig)

| 参数 | 默认 | 说明 |
|---|---|---|
| `mm_per_px` | 3 | 正射网格分辨率 |
| `base_disk_r_mm` | 300 | 局部基准面开运算半径(>最大矿石半径) |
| `fg_prominence_mm` | 40 | 前景凸起阈值(碎料床以下不进前景) |
| `seed_h_mm` | 8 | 细种子深度(略高于平滑后噪声) |
| `hmax_delta_mm` | 18 | 鞍点合并深度(欠/过分割总旋钮) |
| `drop_delta_mm` | 12 | 自由边界跌落判据(2σ深度噪声, 扫描选优) |
| `waist_max_ratio` | 0.55 | 腰线比例(并排接触判定) |
| `free_ratio_min` | 0.85 | 完整性: 自由边界占比下限(0.95 过严, 见配置注释) |
| `solidity_min` / `ellipse_iou_min` | 0.85 / 0.90 | 形状校验 |
| `split_h_mm` | 10 | 多峰欠分割检测的谷深阈值(MULTI_PEAK) |
| `thickness_width_max` | 1.10 | 厚度/次轴上限(TOO_THICK 叠合体校验) |
| `min_diameter_mm` | 90 | 统计下限(含10mm缓冲) |
| `bin_edges_mm` | 100/200/300/400/500 | 粒级分箱 |

默认值为 `scripts/param_sweep.py` 扫描结果(扫描集选优+独立种子验证集复核,
两套种子查准率均 100%)。现场真正要调的只有 `hmax_delta_mm`、
`drop_delta_mm`、`free_ratio_min` 三个。

## 4. 验证方法

合成场景生成器按 DS63 规格仿真(VGA、1%距离噪声、边缘飞点、低反射空洞、
碎料床、椭球矿石随机堆叠), 每颗矿石的真实尺寸与可见性已知。

真值"可测"定义: 可见表面保留了矿石平面尺寸(Feret 与次轴截短 <3%),
且顶面 >75% 未被覆盖、完整在 ROI 内(裙边埋入碎料床不算遮挡)。

指标(`scripts/run_synthetic_eval.py`):

- **查准率** = 接受的矿石中真值确实可测的比例, 目标 **>98%**(测错比漏测危害大);
- **查全率** = 真值可测的矿石中被接受的比例, 目标 **>80%**(漏检靠皮带样本量弥补);
- **测量误差** = 最大边长/次轴相对真值误差, 目标平均 <5%。

## 5. 统计偏差与对标(产线阶段)

只测顶层完整矿石得到的是**表层采样分布**, 细粒易漏入堆底会被低估(所有图像法共性,
商业系统 Split-Online/WipFrag 同样存在)。对策:

1. 投产前做一次人工筛分对标, 建立分粒级校正系数;
2. 若可测率过低(<30%), 从工艺解决: 给料端振动布料摊薄矿层;
3. "前景中未被识别为矿石的碎料面积占比"作为粉矿率指标单独输出。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 黑/湿矿石无回波空洞 | Confidence 滤波 + INVALID 边界判定兜底; 必要时换大功率型号或线激光轮廓仪 |
| 矿石间高差小导致欠分割 | 形状校验(solidity/椭圆IoU/交叉校验)拒掉, 宁可少测; 长期可升级深度学习实例分割(SAM零样本或小规模微调) |
| 皮带振动基准漂移 | 每帧用裸露皮带区域动态重估平面 |
| 阳光/粉尘 | 遮光罩、气幕 |

## 7. 部署路线

1. **算法原型 + 合成验证**(当前阶段, 无需相机);
2. **办公室真机验证**: DS63 俯拍地面矿石, Web 页面人工核对分割与尺寸;
3. **现场安装**: 按皮带宽度定安装高度, 接编码器硬触发, 实现 Stage F 跨帧去重;
4. **筛分对标**: 校正表层采样偏差;
5. **工程化**: 精度确认后移植 C++/固化部署。
